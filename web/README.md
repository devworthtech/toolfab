# Toolfab Web Portal

React + Vite portal for HR and Department Heads. Firebase client settings are in `src/firebaseConfig.ts`; no `.env` file is required.

Run from this folder:

```powershell
npm install
npm run dev
```

Build:

```powershell
npm run build
```

Deploy through the root `.github/workflows/deploy-web.yml` GitHub Pages workflow.
